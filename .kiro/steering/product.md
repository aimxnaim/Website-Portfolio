# Product

Personal developer portfolio for **Aiman Naim**, a Full Stack Developer based in Kuala Lumpur. Built as a single-page React app with a **terminal/pixel-OS aesthetic** — styled to resemble a retro operating system with a kernel boot screen, pixel-art window frames, a fixed taskbar, a scrolling system-log ticker, and an interactive terminal emulator.

## Sections

Navigation is tab-based (no router). Five sections accessed via a sidebar rail:

- **About** — typewriter intro terminal with interactive CLI commands
- **Career** — work experience rendered as OS processes with RUNNING/COMPLETED status badges
- **Education** — academic history
- **Projects** — project showcase with modal detail views
- **Stack** — tech stack panel with stat bars and a tools marquee

## Owner

Aiman Naim — `src/constants/index.js` is the single source of truth for all portfolio content (bio, experience, education, projects). Update data there, not in components.
